# 📦 Repository Archived

## Background

As AWS CloudFormation continues to evolve, our development frameworks have evolved to meet new requirements and capabilities. The implementation patterns in this repository no longer align with our current tooling. We are archiving this repository as part of our ongoing efforts to focus on centralized, comprehensive documentation that reflects the current state of CloudFormation resource development.

## What This Means

* **Historical Reference**: The original codebase remains accessible in the previous default branch of this repository
* **Current Documentation**: For up-to-date CloudFormation resource type documentation, please refer to the [AWS CloudFormation Template Reference](https://docs.aws.amazon.com/AWSCloudFormation/latest/TemplateReference/aws-template-resource-type-ref.html)
* **No Further Updates**: This repository will no longer receive updates or maintenance

If you're looking to develop CloudFormation resource providers, we recommend referring to the official [AWS CloudFormation Resource Type development documentation](https://docs.aws.amazon.com/cloudformation-cli/latest/userguide/resource-types.html) for current syntax and properties.

If you're looking to report an issue with a resource provider, refer to the [CloudFormation Coverage Roadmap](https://github.com/aws-cloudformation/cloudformation-coverage-roadmap/issues) repository, or speak with your AWS support representative.
